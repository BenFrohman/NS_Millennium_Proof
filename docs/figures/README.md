# Frohmanian Symplectic Tether figures 1–8 — inventory (23 November 2026, America/Chicago)

This directory is an inventory of the eight documentation figures for the
Frohmanian Symplectic Tether. It does **not** contain a publication-ready
overlaid set. No image in any location searched for this note carries the
required minimal overlays:

- top-left: `Figure N`
- bottom-right: `Benjamin Stanley Frohman | Frohmanian Symplectic Tether | April 2026`

The spelling **Symplectic** in that attribution string is the required
spelling. It was checked against every located figure title; no
`Sympletic` typo was found in the typographic set. Images were not
generated or edited for this inventory, and the typographic Drive set
was not copied into this public tree (see Set B below).

Large-data global regularity remains conditional. This inventory does
not claim that the Clay problem is solved.
