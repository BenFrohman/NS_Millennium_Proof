Side note reporting defects found in the Lean 4 companion formalization of two preprints on conditional Navier–Stokes regularity on the 3-torus (10.5281/zenodo.24079622, 10.5281/zenodo.24080309). An attempted proof of the stated analytic-bridge target produced a kernel-checked proof of its negation: the legacy solution object did not encode the equations (zero field with lifespan 1). The same object makes the legacy cited Beale–Kato–Majda hypothesis uninhabitable, so four conditional theorems were vacuously true; separately, the abstract data structure behind the three-way equivalence presupposed global regularity. The note gives the exact Lean theorems, the corrected encoding (genuine classical solutions on a maximal lifespan, BKM and Kato–Ponce as named cited hypotheses, non-vacuity lemmas) and a reproducibility section.

This is not a solution of the Clay Millennium Problem and proves nothing new about Navier–Stokes regularity. Clay Statement (B) remains open and is a single explicitly labelled open target in the repository.
