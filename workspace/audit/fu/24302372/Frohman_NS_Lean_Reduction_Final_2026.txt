Abstract
Main Theorem (proved conditional reduction, Lean 4/Mathlib, 0 sorry,
standard axioms only).
clay_reduces_to_direction_curvature_bound: for every
ν > 0, assuming the classical periodic Beale–Kato–Majda continuation principle (a
published theorem not formalized here, hence an explicit hypothesis), the named estimate DirectionCurvatureBound(ν) implies Fefferman’s exact periodic Clay statement
Clay_B_exact(ν). The estimate is the single named open conjecture of this program; it
is not proved, the Clay problem is not claimed solved, and the converse implication is not
proved. We present the program across three repositories (fefferman-clay-navier-stokes,
frohmanian-symplectic-tether-regularity, NS_Millennium_Proof), with each result labeled proved, conditional, or open. The corrected fefferman-clay-navier-stokes v1.5.0 has
236 theorem/lemma declarations in source; the logs in the appendix are dated 28 October 2026.

Erratum
(11

2026). The version of DirectionCurvatureBound(ν)
(PeriodicDirectionDepletionBound) in fefferman-clay-navier-stokes v1.0–v1.4, on which
this note was based, required M to be differentiable (two-sided) at every t ∈ [0, T ], including t = 0.
Because the solution predicate does not constrain the velocity for t < 0, that form is false for every
ν: this is the kernel-checked theorem old_periodicDirectionDepletionBound_unsatisfiable
in v1.5.0 (DOI 10.5281/zenodo.24144846). The Main Theorem below was therefore vacuously
true as originally stated. In v1.5.0 the hypothesis requires M continuous on [0, T ] with a right
derivative at each s ∈ [0, T ) satisfying the same inequality; the Main Theorem is re-proved for this
corrected hypothesis, which remains open. The Main Theorem is a conditional reduction, not an
unconditional result, and not a solution of the Clay problem.

• Attained spatial maximum ⇒ BddAbove and supx ∥ω(x)∥ = M ; explicit lemma that real iSup
is 0 on unbounded ranges.
• Derived (not assumed) calculus relations via HasDerivAt: unit-direction curves have orthogonal velocity; polar Pythagoras ∥(ρξ)′ ∥2 = ρ′2 + ρ2 ∥ξ ′ ∥2 ; second-order Leibniz rule
( 21 ∥ω∥2 )′′ = ∥ω ′ ∥2 + ⟨ω, ω ′′ ⟩; Fermat at a maximum. These are one-variable (coordinate-line)
results.
• Concrete 3D Bochner and polar identities and viscous damping inequality at a maximum
(vector algebra with derivative data as inputs).
• Near/far Biot–Savart cutoff absorption algebra (after Constantin–Fefferman 1993).
• Exclusion of periodic linear (Burgers) strain on T3 ; kernel-determinant direction cancellation;
parabolic scaling homogeneity.
• Non-zero constant solutions, and a genuinely non-constant exact periodic shear Beltrami

Audit warnings

titan-audit reported PASS_WITH_WARNINGS from a heuristic flagging iSup/sSup definitions
without a BddAbove guard (Tstar, vorticity_sup_norm, strain_sup_norm, mollified sup norms).
Tstar is EReal-valued (a complete lattice), so that flag is a false positive. The sup-norm definitions
are intentionally unguarded; every pointwise comparison theorem takes a BddAbove hypothesis, and
the zero default is now an explicit lemma. Warnings were not suppressed.
