                                              Abstract
         This note states only what a Lean 4 kernel certificate proves in the companion repository,
     and lists three classical theorems that are not formalized there. Lean proves a conditional
     implication: if the named hypotheses HypothesisB and BKMCriterion hold, then every
     maximal classical solution of periodic incompressible Navier–Stokes is global. Kato local
     existence, Fujita–Kato small-data global regularity, and the Beale–Kato–Majda continuation
     criterion itself are not formalized in this repository and are not claimed as proved or as
     kernel-certified. Clay Millennium Problem Statement (B) remains open.


1   The Lean-certified implication
The companion repository https://github.com/BenFrohman/frohmanian-tether-conditional-regularity
proves, as ClassicalNS.analyticBridge_of_formB, the following statement, which is the only
theorem claimed here.

Theorem 1.1 (Conditional implication). For every bound C⋆ : R → R, if Lean’s HypothesisB
holds for C⋆ and if Lean’s BKMCriterion holds, then for every viscosity ν > 0 and every
smooth, periodic, divergence-free initial datum, every maximal classical solution (an object of
                                                    ∫T
type NSSolution) is global (T ⋆ = ⊤) and has finite 0 ∥∇u(t)∥L∞ dt for every finite T > 0.

    The two hypotheses are named assumptions in the Lean development. They are not proved
in Lean. An independent review of whether those encodings are faithful to the textbook Beale–
Kato–Majda criterion, and whether they are vacuous, is in progress. This note transcribes the
Lean statement as it stands. The unconditioned analytic-bridge statement is recorded only as
the proposition analytic_bridge_unconditional_Statement, which has no proof.
    The oﬀicial kernel certificate is the GitHub Actions artifact for the commit and run in the
certificate block below.


2   Open formalization items
Earlier versions of this note stated three classical theorems with proof sketches: Kato local
existence and a lifespan bound (former Theorem 2.1), Fujita–Kato small-data global regularity
(former Theorem 3.1), and the Beale–Kato–Majda continuation criterion (former Theorem 4.1).

present them as proved and does not attach a kernel certificate to them. Formalizing each of
them in Lean, with only the standard axioms and no sorry, is left open.
