Preprint (not peer reviewed), version 1.4.0 of the Clay- (Fefferman Statement (B) on 𝕋³) record series. It documents a Lean 4/Mathlib formalization, in the public repository GitHub BenFrohman/Clay- (library theorems merged in PR #9, commit 43653aa; files here built from main at commit c53fb33e1cd3c33383bfda656329000d01ef919a), of the spatial half of Theorem 1 of Deng, Hou and Yu (DHY): along a nonvanishing vortex-line segment from x to y, |ω(x)| ≤ e^C |ω(y)| whenever |∫₀^L (div ξ)(γ(s)) ds| ≤ C, where ξ = ω/|ω|.

What Lean proves. The named target SpatialBridgeObligation holds for every packet of solution-linked vortex-line data over every smooth periodic Navier–Stokes solution in the repository's encoding. As a consequence, finiteness of the time integral of the endpoint vorticity implies finiteness of the Beale–Kato–Majda (BKM) integral. Every step of the argument is also written out on paper. The library axiom audit at c53fb33 reports 133 theorems / 244 declarations using only propext, Classical.choice and Quot.sound, with no sorry.

What is assumed, not proved. The theorems are conditional. They carry the full solution predicate NSOn, all packet fields (near-maximality, nonvanishing along the segment, the vortex-line tangent equation, integrability of div ξ, a time-uniform bound C) and, for the BKM consequence, the endpoint-integrability hypothesis.

Kernel-checked limitations. (1) The argument uses only spatial C² smoothness, so it is kinematic and not specific to Navier–Stokes. (2) The endpoint hypothesis is equivalent to BKM finiteness, so the criterion moves the analytic difficulty rather than removing it. (3) Smoothness-index correction: earlier versions of this record series wrote a bare ⊤ in SmoothPeriodicData/NSOn, which at the pinned Mathlib means real-analytic (ω), not C^∞. PR #11 (merge commit c53fb33) now uses ∞ (C^∞); the same proofs and axioms go through. An informal, unformalized shear-flow argument (conditional on classical uniqueness) indicates the earlier formal Statement (B) was false as written.

Open / not formalized. Existence of vortex-line packets for any nonzero solution; endpoint integrability; general and degenerate DHY packets and the two-sided ratio bound; DHY Theorem 2 and Lemmas 2–3; local existence/uniqueness and the BKM continuation theorem (only a named proposition). PeriodicBKMIntegrability and Fefferman's Statement (B) remain open.

This is not a proof of the Clay Millennium Navier–Stokes problem and does not prove global regularity for any class of data. Kernel checks confirm the Lean statements as written; they do not establish fidelity to the intended PDE notions or physical correctness.
