## Result (exactly what the Lean kernel proves; locked by the Truth Gate)

For the velocity-slot Frohmanian tether with pointwise vorticity weight,
`B(a,b) = −κ ∫_{𝕋³} |ω|² (Π_u a · Π_u b) dx`, generated by the kinetic energy `H = ½‖u‖²`:

- (a) `B(a, u) = 0` for every continuous `u` (energy degeneracy, proved, not assumed);
- (b) the `L²` gradient of `H` is `u`;
- (c) the tethered weak right-hand side equals the Navier–Stokes one;
- (d) the model and Navier–Stokes on `𝕋³` have the same smooth solutions on `[0,∞)`;
- (e) global regularity of the model ⇔ global regularity of Navier–Stokes on `𝕋³` (formulation of the paper);
- (f) any property holds for all model solutions ⇔ it holds for all Navier–Stokes solutions;
- (g) `B(a,a) ≤ 0` for `κ ≥ 0`; (h) `B = −4π²κ` at the Beltrami field `(0, sin 2πx₀, cos 2πx₀)` with `a = (1,0,0)`;
- (i) for `κ > 0` the tether is not positive semidefinite; (j) the factorized-weight variant `−κ‖ω‖²⟨Π_u a, Π_u b⟩` has the same degeneracy and sign.

**Global regularity of the tether model is not proved.** By (e) it is the same open problem as
periodic Navier–Stokes global regularity. The cubic sink `d/dt ‖ω‖_{L∞} ≤ C‖ω‖²_{L∞} − κ''‖ω‖³_{L∞}` is not supplied by the
tether (by (f) it is the same question as for Navier–Stokes). Not a Clay Millennium Problem claim.
